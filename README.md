# CKD Genetic Target Prioritization

## Project Overview
A reproducible bioinformatics project to explore genetic associations
with kidney function and prioritize candidate genes for further study.

## Research Questions
- Which genetic variants are associated with estimated glomerular
  filtration rate (eGFR)?
- How can variant-level evidence be connected to candidate genes?
- Which candidate genes warrant further investigation in chronic
  kidney disease research?

## Planned Workflow
1. Acquire and document public GWAS summary statistics.
2. Inspect data quality and summarize genetic associations.
3. Visualize association signals and genomic distributions.
4. Explore variant-to-gene evidence and candidate prioritization.
5. Document the workflow for reproducibility.

## Data
The project will use publicly available research data.
Source, phenotype definition, ancestry, and limitations will be
documented before analysis.

## Tools
Python, pandas, NumPy, SciPy, Matplotlib, Git, and Linux.

## Important Note
eGFR is a measure of kidney function and is not identical to a
clinical diagnosis of chronic kidney disease. Candidate genes from
this project will be research hypotheses, not validated drug targets.
